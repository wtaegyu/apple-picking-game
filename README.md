# Apple Picking Game

나무의 사과 8개를 클릭해 모두 수확하는 간단한 웹 게임입니다.

## 실행 방법

1. GitHub 저장소에서 **Code > Download ZIP**을 누릅니다.
2. 내려받은 ZIP 파일의 압축을 풉니다.
3. 압축을 푼 폴더에서 **index.html**을 더블클릭합니다.
4. 사과를 클릭하면 점수가 올라갑니다. **다시 시작**으로 새 게임을 시작합니다.

## 파일

- `index.html`: 게임 화면, 디자인, 동작이 모두 들어 있습니다.
- `README.md`: 프로젝트 설명과 실행 방법입니다.

설치할 프로그램이나 외부 라이브러리가 없습니다. Chrome 또는 Edge에서 실행할 수 있습니다.

GitHub 웹사이트의 파일 업로드와 다운로드를 배우기 위한 수업용 예제입니다.
